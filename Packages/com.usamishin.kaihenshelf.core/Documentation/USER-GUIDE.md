# KaihenShelf Unity Editor版 0.1.147

旧名称の版から更新すると、共通データは `%LOCALAPPDATA%/KaihenShelf/Unity`、プロジェクト内の履歴と画像は `UserSettings/KaihenShelf`、作業データは `Library/KaihenShelf` に移行します。保存済み画像への参照も更新します。書き換え前のJSONは `.before-kaihenshelf.bak` に保持します。新旧保存先が両方存在し、移行完了記録がない場合は上書きせず停止します。

Unity内の配置は `Assets/KaihenShelf`、UPMパッケージIDは `com.usamishin.kaihenshelf.core` です。旧UPMパッケージとの同時導入は避け、旧パッケージを新パッケージに置き換えてください。UnityPackage更新はスクリプトGUIDを維持しています。開発用更新スクリプトは旧フォルダを確認・バックアップした上で移行します。

「フォルダから追加登録」でフォルダを選ぶと「情報を編集」が開きます。登録済みショップを検索して選ぶか、下の欄へ自由入力できます。「フォルダ内のテクスチャから選択…」で、子フォルダを含むPNG/JPEGをプレビューして商品サムネイルに設定できます。32MB以下・各辺4096px以下の画像を受け付け、元画像を変更せず縮小画像を保存します。

インポート履歴は新しい順に1ページ20件で表示します。上部の「‹」「›」で切り替えられ、新しくインポートすると先頭ページへ戻ります。ページングによって古い履歴が削除されることはありません。

## タグ・ショップによる分類条件

「インポート先・分類設定」で、サブカテゴリ／タグを含む／タグを含まない／ショップを含む／ショップを含まないを選べます。
サブカテゴリと「タグを含む」「ショップを含む」はいずれかに一致すれば対象になり、「タグを含まない」「ショップを含まない」のいずれかに一致すれば、その分類を飛ばして次の分類を判定します。除外条件だけでは分類しません。
タグとショップ名は完全一致です。`*hair*` のように `*` を付けると部分一致になります。ショップは登録されている表示名で判定します。変更は「保存して適用」で反映され、商品ごとの手動分類が優先されます。

衣装扱いの髪を移す設定例：衣装に「タグを含まない」で `髪`、`髪型データ`、`LongHair` を別々に追加し、髪型に同じ3つを「タグを含む」で追加します。髪型の「タグを含まない」に `ノーマルマップ` を追加すると、髪用ノーマルマップの誤分類も避けられます。タグの付け方は商品ごとに異なるため、すべての髪商品を網羅する条件ではありません。

Windows 10/11・Unity 2022.3 LTS向けのEditor拡張です。BOOTH Library Manager連携・非公式です。左メニューの「使い方・ポリシー」でも最新の操作説明と読み取り・保存・通信範囲を確認できます。

アプリ内の使い方は、初めての方向けに「商品を読み込む → 使いたい商品を探す → Unity内の保存先を確認する → インポートする」の4枚のカードで案内します。手順番号はグレーで表示します。「詳しい使い方（説明サイト）を開く」から、画像付きの操作ガイド https://usa-mishin.github.io/KaihenShelf/guide/usage を開けます。この配布ガイドにも各機能の詳しい説明を掲載しています。

## VCC／ALCOMで導入

配布リポジトリ https://usa-mishin.github.io/KaihenShelf/index.json を追加し、対象プロジェクトにKaihenShelfを追加します。旧UnityPackage版のツール本体は置き換え対象です。切り替え前にUnityを閉じ、プロジェクトをバックアップしてください。

紹介・導入ガイド: https://usa-mishin.github.io/KaihenShelf/guide/

## 手動で導入

1. `KaihenShelf-0.1.147.unitypackage` をUnityの `Assets > Import Package > Custom Package` から導入します。
2. `KaihenShelf > KaihenShelf` を開きます。
3. 読み取り・保存・通信範囲を確認し、同意して開始します。

UPM/VPM版との二重導入はしないでください。VRChat SDKなしでも動作し、アバター用のランタイムコンポーネントは追加しません。通常インポート後の整理機能は廃止されています。0.1.91以前のUnityPackage版から更新する場合は、旧 `Editor/Import/AssetRelocator.cs` と `Editor/UI/AssetMoveWindow.cs` および各 `.meta` を除去してから更新します。商品アセットや設定は削除しません。

## 1. データを読み込む

KaihenShelf > KaihenShelfから起動し、ポリシーを確認して同意すると、BOOTH Library Managerの商品を自動で読み込みます。商品が表示されるまでお待ちください。読み込めない場合は、表示・連携設定の「BOOTH Library Managerの保存場所（DB）」を確認し、左下の「最新データを取得して更新」を押してください。標準のDBは %APPDATA%\pm.booth.library-manager\data.db です。別の場所にある場合は「参照…」で選択します。商品の保存先はBOOTH Library ManagerのDB内の設定から取得します。

BOOTH Library Managerを使わない商品は「フォルダから追加登録」、未購入のアバターは「未購入アバター追加」から登録できます。

## 2. 商品を探す

アバター／アイテム・アセットで商品名・タグを検索できます。アイテム・アセットの検索枠内ではショップ・BOOTHタグ・BOOTHカテゴリ・年齢制限・対応アバター、お気に入り・無料／ギフトを指定できます。BOOTHカテゴリは登録商品の「カテゴリ > サブカテゴリ」、年齢制限は「全年齢のみ」（初期値）・「R18商品のみ」・「指定なし」から選びます。対応アバターは「エク」などのアバター名で表示します。「リセット」で検索と分類を戻します。

分類は色付きタブで切り替えます。ツール・シェーダー・ワールド・その他は対応アバター判定の対象外で、アバター絞り込み中も表示します。ソートはページ番号の左にあり、初期値は「↓ 登録日時（新しい順）」です。ショップ・BOOTHタグのカードからも絞り込めます。

## 3. 商品詳細・情報の編集

商品カードの画像・タイトル・「詳細」で別ウィンドウを開き、ファイル一覧を自動取得します。「お気に入り」「情報を編集」「商品ページ」「保存フォルダ」を利用できます。ショップカード、対応アバター名、BOOTHタグをクリックすると一覧を絞り込みます。BOOTHタグは先頭10件を表示し、「すべて見る」で全件を確認できます。

「情報を編集」は専用ウィンドウで開き、変更を自動保存します。アバター名・識別タグ・共通素体、商品の分類や対応アバターを調整できます。識別タグ欄にはアバター名が固定で入り、追加タグを個別に入力できます。手動編集した設定はデータ再取得でも保持します。

## 4. 対応アバター・購入形態

アバター識別タグの文字で対応アバターを自動判定します。購入済みバリエーション名にアバターが明示される単体購入は購入名だけを照合し、明示されない場合やその他の購入形態は商品名・説明・タグ・バリエーション・取得済みファイル名を使います。共通素体による間接対応は括弧内に表示します。誤判定は「情報を編集」の対応アバター表で修正できます。

明示的なフルパック表記、または購入済みバリエーション名がない場合はフルパック、それ以外の名前ありは単体購入です。BOOTH Library Managerでバリエーションはあるが購入注文との関連がない場合は「無料/ギフト」と表示します。「BLM更新あり」はBOOTH Library Managerの未読更新通知に基づき、BOOTHの最新版を直接確認する表示ではありません。

## 5. 分類条件を変更する

「インポート先・分類設定」の表で「サブカテゴリ」「タグ」「ショップ」の条件を追加できます。含む条件はOR、含まない条件は一致した分類から除外します。名前は全角・半角や英字の大文字・小文字を正規化して照合します。サブカテゴリは完全一致、タグとショップ名は * で任意の文字列に一致します（例：*material*）。複数分類に一致した場合は表の上から優先し、一致なしは「その他」、商品ごとの手動分類が最優先です。

初期条件はBOOTHのサブカテゴリと、マテリアル分類の「肌マテリアル」「*マテリアル*」「*material*」「*matcap*」タグです。マテリアルをテクスチャより優先します。「保存して適用」で配置先と分類条件をまとめて保存し、現在の商品と次回以降の再取得に反映します。「初期条件に戻す」も適用するまでは保存済み条件を変更しません。

ショップ条件の初期設定には、衣装の「ショップを含まない」と髪型の「ショップを含む」に、それぞれ `GLAY Unknown` と `DanaStudio` を登録しています。新規利用時と「初期条件に戻す」で使用し、更新時に保存済みの条件へ自動追加はしません。

## 6. ファイルを確認する

詳細右側の「ファイル名検索」と、UnityPackage／テクスチャ／画像編集データ／3Dデータ／その他ファイルのタブを使います。UnityPackageはアバター名・マテリアル、バージョン、同一名あり、旧バージョンを表示し、関連する旧版や同名ファイルを親カード内にまとめます。「同一名あり」は内容の一致を意味しません。

他の4タブはフォルダ階層で表示し、「すべて展開／すべて閉じる」で開閉できます。PNG・JPEGと、対応JPEGプレビューを含むPSD・PSBはサムネイルと拡大表示に対応します。表示できない形式は種類アイコンになります。ファイルカードをクリックするとPCの既定アプリで開き、フォルダの「開く」で保存場所を開きます。

## 7. インポートする

「インポート先・分類設定」で分類別のAssets内の配置先を設定します。衣装・髪型・アクセサリー・テクスチャ・マテリアル・ギミック・アニメーション・シェーダーは同名フォルダが初期値です。空欄は元のAssets配下の構成を維持し、アバターはこの設定で固定です。

UnityPackageの「インポート」を押し、確認画面でファイルと配置先を確認して「Import」を押します。同じGUIDは現在の場所で更新し、同名フォルダは共有します。別GUIDの同名ファイルは競合として停止し、同一内容は書き込みを省きます。再圧縮や導入後のフォルダ移動は行いません。

複数のUnityPackageは、見出し右の「一括インポート」からチェックを付け、「〇個を一括インポート」を押します。選択したカードは青色になります。続いて通常と同じ確認ウィンドウが開くので、統合されたファイル一覧・商品サムネイル設定を確認し、「Import」で実行します。「Cancel」またはウィンドウを閉じると取り消します。マテリアルとPrefabが別パッケージの場合は両方を選択してください。確認画面で必要なマテリアルを外すと依存検査で停止するため、選択を戻して再実行できます。

一括インポートは選択した内容を事前にまとめ、GUIDを保持して全ファイルを配置してからUnityに読み込ませます。同じGUID・同じ内容は共通データとして一度だけ配置し、同じGUIDで内容が異なる共通ファイルは、採用するパッケージをファイルごとに選択してから通常の確認画面へ進みます。選択した設定は、そのファイルを参照するすべてのアセットに適用されます。同じ配置先のフォルダは、GUID以外の設定が一致し、省かれるフォルダGUIDへの参照が見つからない場合にまとめます。別GUIDの同名ファイルなど、解決できない配置先の競合は書き込み前に停止します。検出できるマテリアル・シェーダー不足も事前に通知します。完了後はPrefabを再読込してProject表示を更新します。商品サムネイルは確認画面の指定を使い、取り込み対象のあるパッケージの履歴を記録します。シェーダー・SDKなどの前提ソフトは先に導入してください。コードやバイナリ内の依存関係をすべて判定する機能ではありません。

テクスチャの「インポート」は、検索条件にかかわらず選択フォルダ配下のPNG・JPEG・TGA・EXRを対象にします。Assets／テクスチャのインポート先設定／ショップ名／選択フォルダ名／元の階層へ配置します。画像編集データなど他の形式は取り込みません。

スクリプトや外部依存を含む商品の動作確認は別途必要です。固定パスを前提としたアセットは配置先の変更で動かなくなる場合があるため、配布元の導入手順を確認し、必要ならインポート先を空欄にしてください。

## 8. 商品サムネイル・インポート履歴

確認画面の「商品サムネイル設定」でUnityのProjectフォルダに商品画像を設定できます。ショップ画像は使用しません。別商品が同じ親フォルダを使う場合は、商品ごとの直下の子フォルダへ表示し、複数商品で共有する子フォルダには表示しません。フォルダ自体は移動しません。

Projectの右クリック > KaihenShelf Image > フォルダ画像を設定から手動設定できます。KaihenShelf > KaihenShelf Image > Showで表示を切り替えられます。

インポート履歴には商品サムネイル・商品名・PCの現地時刻・インポート数を表示します。「インポート先を開く」でUnityのProject内の配置先、「アイテムを見る」で商品詳細を開きます。「履歴をリセット」は現在のプロジェクトの履歴のみを消し、アセットは削除しません。

## 9. 再取得・困ったとき

BOOTH Library Managerの商品情報の更新は左下の「最新データを取得して更新」で行います。BOOTHへのログインや商品ファイルのダウンロード、定期自動同期は行いません。ネット復旧後に画像が戻らない場合も「最新データを取得して更新」かウィンドウの開き直しで再試行できます。

下部の通知は1行表示で、マウスを重ねると全文を確認できます。インポート後はUnityのConsoleも確認してください。容量不足や不正なパスなどで停止した場合は表示内容を確認し、長いパスはプロジェクトや配置先の名前を短くしてください。通常インポート済みアセットを後から整理・移動する機能はありません。


## 表示・操作の補足

- 商品詳細は独立したEditorウィンドウで、ドッキングや別モニターへの移動に対応します。左の商品情報と右のファイル一覧はそれぞれスクロールできます。
- 一覧カードの大きさは固定です。商品名は元の表記を保ち、2行を超える部分を「…」で省略します。全文はマウスを重ねるか詳細で確認できます。
- 商品詳細のアバター識別タグではメイン呼称をクリックしてアイテム・アセットを絞り込めます。共通素体が設定されている場合は「（〇〇と共通素体）」を表示します。
- 商品詳細の対応アバター見出しの右に「（購入済み：〇〇）」、該当する場合は「（無料/ギフト）」を表示します。フルパック・単体購入のチップは表示しません。
- アバター識別タグのアバター名行は編集不可です。名称の変更は同じ編集ウィンドウ上部の「アバター名」欄で行います。
- BOOTHの年齢制限情報がある商品を表示・連携設定の「R18商品を一覧・履歴から非表示」で一覧とインポート履歴から非表示にできます。この設定は検索の年齢制限より優先します。非表示の商品を除いて履歴の件数・ページ数を計算し、記録自体は残します。年齢制限情報のない商品を名称・タグから推測して非表示にはしません。
- UnityPackageの「開く」は保存場所を開きます。旧版・同名判定は商品内のファイル名や親フォルダ名によるもので、ネット上の最新版を確認する機能ではありません。
- テクスチャのPNG・JPEGはプレビュー対象です。PSD・PSBは対応するJPEGプレビューが埋め込まれている場合のみ表示できます。TGA・EXR、CLIP・SAI・SAI2やプレビューのないファイルは種類アイコンを表示します。
- 3Dデータとその他ファイルは縦並びのカードです。Windowsから拡張子ごとのアイコンを取得できない場合はUnityの種類アイコンを表示します。
- JSON設定はPC内で共通、インポート履歴・フォルダ画像はプロジェクトごとです。複数Editorで同時に設定を編集すると最後の保存が優先されます。

## インポートの補足

一般的なGUIDディレクトリ形式のUnityPackageを検査し、一時展開して、選択したアセットと.metaを直接配置します。空欄の配置先は「すべてのファイルをAssets直下へ平坦化する」という意味ではなく、元のAssets配下の階層を維持する設定です。同じGUIDのアセットがすでにある場合は、その現在位置で更新します。

確認画面はUnity標準に近い表示の専用ウィンドウです。All／Noneとフォルダのチェックで選択し、最終パスは行のツールチップで確認できます。すべて導入済みの場合はその旨を表示し、OKで商品サムネイル設定だけを反映できます。テクスチャの更新では既存GUIDとインポート設定を保持し、元フォルダの.metaは取り込みません。

空き容量、危険なパス、リンク、重複、対応画像のヘッダーなどを配置前に検査します。Windowsでmetaを含め260文字以上になる配置先、Unityが無視する名前、Packages配下への展開は対象外です。画像の画素データ全体の復号とアセットの読み込み・コンパイルはUnityが行います。履歴の「配置完了」は、Unity内での商品動作まで保証する表示ではありません。

書き込み失敗時はそれまでの変更の復元を試みます。復元に失敗した場合はバックアップを保持して場所を表示します。強制終了後は一時データが残る場合があるため、表示された記録とUnityのConsoleを確認してください。

フォルダ画像は商品の導入記録で共有関係を判定します。通常のUnityインポートなど、本拡張機能に導入記録がないファイルの共有関係は自動では特定できません。既存商品の記録を保持し、複数の商品が使う子フォルダには画像を設定しません。手動設定はProjectの右クリックメニューで行えます。

## 現在の対象範囲

このPCのBOOTH Library Manager実データとUnity 2022.3.22f1のtestプロジェクトで確認しています。すべてのBOOTH Library Managerバージョン・商品・Unity環境への適合を保証するものではありません。未知のDB形式や読取エラーではエラーを表示し、既存一覧を維持します。

BOOTHからの商品ファイルのダウンロード、定期自動同期、Windowsアプリ版library.dbとの同期、通常インポート後の整理、Pro課金・認証は含みません。配布用UPM/VPM ZIPの生成とVCCリポジトリの公開は別です。

## ポリシー

BOOTH、BOOTH Library Manager、ピクシブ株式会社、VRChat、Unityが提供・保証・承認する製品ではありません。

### 読み取る情報

同意後、BOOTH Library ManagerがPC内に保存した商品名・説明・ショップ・分類・タグ・URL・画像URL・保存先・日時・年齢制限・購入済みバリエーション・更新通知を読み取ります。DBは読み取り専用で開きます。商品詳細では選択した商品フォルダを走査し、ファイル名・更新日時・サイズと、表示可能な画像やPSD／PSBの埋め込みプレビューを読み取ります。インポート時は選択ファイルとUnity内の配置先・GUID・既存ファイルを検査します。

### 保存・変更する範囲

商品情報のキャッシュ、分類条件、アバター設定、お気に入り、未購入アバター、インポート先設定、同意の版番号と日時は %LOCALAPPDATA%\KaihenShelf\Unity\state.json に保存します。この設定は同じPCのUnityプロジェクト間で共通です。直前のJSONは .bak に保存します。

インポート履歴は現在のプロジェクトの UserSettings/KaihenShelf/history.json、フォルダ画像の設定と縮小画像は同じ場所の FolderThumbnails に保存します。画像はAssetsへ追加せず、ビルドに含めません。作業用の一時展開・バックアップ・配置記録は Library/KaihenShelf に保存します。

### 元データとインポート

この拡張機能はBOOTH Library ManagerのDB・元の商品ファイル・Windowsアプリ版のlibrary.dbを書き換えません。インポートはユーザー操作と専用の確認画面を経由し、選択したファイルを現在のUnityプロジェクトのAssetsへ新規作成・更新します。Unity標準に近い表示ですが、この拡張機能の確認画面です。

一時展開データは通常の終了・キャンセル時に削除します。書き込み失敗時は復元を試み、復元に失敗した場合はバックアップを保持して場所を表示します。強制終了時は一時データが残る場合があります。履歴のリセットや同意取消は、導入済みアセットや保存済み画像を削除しません。

### 通信と外部アプリ

商品画像はローカルを優先し、取得できない場合やショップ画像の表示時は保存済みのHTTPS画像URLから取得します。接続先は booth.pximg.net、booth.pm とそのサブドメインに限定し、リダイレクトには追従しません。画像配信先には画像URL・IPアドレスなど通常の接続情報が伝わります。ログイン情報やCookieを画像取得に送信しません。

通常のサムネイルとプレビューは上限を設けたメモリ内キャッシュです。フォルダ画像に設定した商品画像だけは、最大128pxの縮小画像を上記のプロジェクト内へ保存します。「商品ページ」は既定ブラウザーでBOOTHを開き、ファイルカードはPCの既定アプリへ元ファイルのパスを渡します。外部アプリの通信や編集・保存は、そのアプリの動作に従います。

### 取得しない情報・停止方法

BOOTHのパスワード、ブラウザーCookie、VRChatアカウントは読み取りません。この拡張機能による広告、テレメトリー、自動クラッシュ送信、独自サーバーへの商品データ送信はありません。

表示・連携設定の「同意を取り消して読み取りを停止」で利用を停止できます。保存済みの設定・商品情報・履歴・フォルダ画像は残ります。複数のUnity Editorで同時に設定を編集すると最後の保存が優先されるため、設定の編集は1つのEditorで行ってください。

### 自動判定・動作の範囲

分類・対応アバター・購入形態・旧バージョン・同名判定は、取得できた情報に基づく補助機能です。誤判定は商品情報の手動編集などで確認・修正してください。パッケージの検査は危険なパスや容量などを確認しますが、アセットのコードの安全性、固定パスへの依存、必要なシェーダー・SDKの充足、導入後の正常動作を保証するものではありません。商品ごとの利用規約・ライセンスと配布元の導入手順に従って利用してください。

対応アバターが0件、または判定対象外の分類は「対応アバターなし」と表示します。アバター絞り込みでも表示し、アバターを選んでいる間は「対応アバターなしを除外」で非表示にできます。アバター選択を解除すると除外チェックも解除されます。共通素体のみの対応を除外した商品を、対応アバターなしとして再表示することはありません。

「インポート済」「済」は現在のプロジェクトの正常終了した履歴に基づきます。導入後のファイルの有無や最新版かどうかを保証する表示ではありません。履歴をリセットすると表示も消えます。

既定一覧にないアバターの生成済み識別タグとメイン呼称は、商品名が変わっても同期時に保持します。識別タグがまだない場合は生成します。手動編集した識別タグは引き続き保持します。

フォルダ登録アイテムのサムネイルは、情報を編集 → フォルダ内のテクスチャから選択で設定します。サブフォルダを含むPNG/JPEG（32MB以下・各辺4096px以下）を検索・プレビューし、この画像に設定を押します。元画像はそのまま、最大256pxの画像をアプリの保存領域に作成します。
