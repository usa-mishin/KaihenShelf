# KaihenShelfをはじめる

Windows用のUnity Editor拡張です。動作確認環境は **Unity 2022.3.22f1**。VRChat SDKはこのツール自体の必須条件ではありません。取り込む商品に必要なSDKやシェーダーは、商品の説明に従って先に導入してください。

## 1. プロジェクトに追加

VCCまたはALCOMをインストールしたPCで、下のボタンを押します。配布元を追加したら、対象プロジェクトのパッケージ管理画面で **KaihenShelf** を追加してください。

<RepoLink />

ボタンはPCに登録された対応アプリを開きます。開かない場合は、配布URLをコピーし、VCC／ALCOMのリポジトリ追加画面に貼り付けてください。

## 2. Unityで開く

Unity上部の **KaihenShelf → KaihenShelf** を選びます。読み取り・保存・通信範囲を確認し、同意して開始してください。

## 3. 商品の読み込みを待つ

同意後、BOOTH Library Managerの商品を自動で読み込みます。商品が表示されたら、使い始められます。

読み込めない場合は、**表示・連携設定**で保存場所（DB）を確認し、**データ再取得**を押してください。標準の場所にない場合は「参照…」でDBを指定できます。商品情報を更新したいときも「データ再取得」を使います。

商品ファイルは、あらかじめBOOTH Library Managerなどでダウンロードしてください。KaihenShelfはBOOTHへのログインや商品ファイルのダウンロードを行いません。

手元のフォルダは **フォルダから追加登録** でも登録できます。

## 既存版から切り替える

プロジェクトをバックアップし、Unityを閉じてからVCC／ALCOMで追加してください。旧UnityPackage版のツールフォルダはパッケージへの切り替え時に置き換え対象になります。商品アセットをツール本体のフォルダに入れないでください。

設定はPC内、履歴とフォルダ画像はプロジェクトのUserSettings内に保存されます。パッケージ本体の外にあるため、通常の更新では保持されます。旧名称の保存先は初回起動時に移行します。新旧データの競合が表示された場合は上書きせず、表示された保存先を確認してください。

## 手動で導入する

[GitHub Releases](https://github.com/usa-mishin/KaihenShelf/releases) のUnityPackageを、Unityの **Assets → Import Package → Custom Package** から導入できます。VCC版との二重導入は避けてください。更新はVCC／ALCOMの利用をおすすめします。

次は [使い方](./usage) をご覧ください。
